# Whack-a-Mole Game

A simple browser-based Whack-a-Mole game built using HTML, CSS, and JavaScript. The game tests reaction speed by requiring users to click on randomly appearing targets within a limited time.

## Features

* Random mole appearance logic
* Score tracking
* Time-based gameplay
* Lightweight and runs directly in the browser

## Tech Stack

* HTML
* CSS
* JavaScript

## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/whack-a-mole-game.git
cd whack-a-mole-game
```

Run the project:

* Open `index.html` in your browser
